# Gs---edge

# Autores: Leonardo Borges da Costa RM: 565966 e Pedro Henrique Araújo de Abreu RM: 561924

# Esse projeto implementa um sistema de monitoramento ambiental utilizando um ESP32 conectado a sensores de temperatura, umidade e luminosidade. O objetivo é acompanhar as condições do ambiente e identificar situações que possam exigir atenção, enviando informações continuamente por meio de comunicação MQTT e requisições HTTP. O dispositivo realiza leituras periódicas dos sensores, organiza essas informações em formato JSON e transmite para serviços externos. Além disso, o sistema possui uma lógica de detecção de alerta que identifica temperatura elevada, umidade acima do ideal ou baixa luminosidade. Quando qualquer uma dessas condições críticas ocorre, o ESP32 aciona alertas visuais e sonoros através de um LED e de um buzzer, além de enviar uma notificação específica via MQTT. O código também permite receber comandos externos enviados através de um tópico MQTT dedicado, possibilitando acionar manualmente o sistema de alerta ou implementar outros comportamentos conforme necessário. Toda a comunicação é realizada de forma automática, mantendo a conexão ativa com a rede Wi-Fi e com o broker MQTT, garantindo que o monitoramento seja contínuo e confiável. Com isso, o projeto proporciona uma solução simples e funcional para acompanhar o estado do ambiente, permitindo integração com sistemas externos, automação, análise ou registro dos dados coletados. É um sistema flexível, que pode ser adaptado para diferentes cenários de uso, como ergonomia, segurança, conforto ambiental ou monitoramento de espaços específicos.
